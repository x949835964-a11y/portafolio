# Portafolio Personal - Diego Gamonal

¡Bienvenido a mi repositorio de portafolio web! Este proyecto está diseñado para mostrar mis habilidades como desarrollador web y de sistemas.

## Estructura de Archivos
* **`index.html`**: Contiene la estructura semántica principal del sitio web, secciones de presentación, biografía, servicios y proyectos.
* **`style.css`**: Hoja de estilos moderna con soporte para diseño adaptable (*responsive*), variables CSS y modo oscuro/claro automático.
* **`script.js`**: Archivo de lógica en JavaScript para la interactividad, menú móvil, animaciones y cambio de tema.
* **`favicon.svg`**: Ícono vectorial personalizado para la pestaña del navegador.
